## 多语言扩展（58 种语言）

### 新增
- **55 种语言 + 繁体中文**，加上简体中文共 **58 个语言包**
- 安装器带语言菜单，并会按系统 UI 语言**自动推荐**对应版本
- Google 翻译批量管道：占位符 `%s/%d/%c`、行首颜色码 `Y/G/O/-`、`\n/\t` 全程哨兵保护

### 说明
- 非中文语言为机器翻译产出，质量随语种差异较大
- 显示效果取决于 Windows「非 Unicode 程序语言」是否与该语言代码页一致（安装器会检测并提示）

### 支持边界
仅支持 Windows 存在 ANSI 代码页的书写系统（63 种）；印地语、泰米尔语、高棉语等 30+ 种
因 1996 年 ANSI 程序的架构限制无法实现，详见 [docs/LANGUAGES.md](docs/LANGUAGES.md)。

---

**安装**：把 `RoadRash-30th-Localization.exe` 放进游戏目录（与 `RoadRash95.exe` 同级），双击运行，按提示选语言。
