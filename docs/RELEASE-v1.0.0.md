## 简体中文

### 内容
- **1372 条全部人工翻译**，其中 983 条中文化（71.6%）
- 用游戏**官方德/法/西/意四个本地化版本逐条对照校核**，修正了一批误译：
  `sheer`→陡峭、`ex-con`→蹲过大牢、`pussycat`→小猫、`Fidgety`→躁动、`dopest`→骑得最烂
- 行首颜色码、`%s/%d/%c` 占位符、`\n/\t` 全部原样保留
- 8 个车手短名保留英文（参与人物立绘路径，翻译会掉图）

### 安装器
- **单文件 exe**，内嵌语言包，放进游戏目录双击即用
- 自动备份、自动提权、幂等、自带卸载
- EXE 仅 2 处等长字节补丁（字体字符集 + 字体名），不加代码

### 前置条件
系统「非 Unicode 程序语言」需为 **中文(简体, 中国)**，否则汉字会显示为 `?`。
